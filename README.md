# EcoTech Solutions

Trabajo práctico de programación en Python e integración con Django.

## Ejercicio 1 – Sanitización y análisis de sensores (20 puntos)

- Normalización de registros.
- Limpieza de temperaturas.
- Cálculo del promedio térmico.
- Generación de alertas.

## Ejercicio 2 – Modelo de productos y persistencia (40 puntos)

- Programación orientada a objetos.
- Herencia, encapsulamiento y polimorfismo.
- Excepciones personalizadas.
- Exportación del catálogo en formato JSON.

## Ejercicio 3 – Auditoría e integración web (40 puntos)

- Cálculo de emisiones de carbono.
- Cinco pruebas unitarias con unittest.
- Procesamiento de consumos industriales.
- Panel de sustentabilidad desarrollado con Django.

## Tecnologías utilizadas

- Python
- Django
- HTML y CSS
- JSON
- Unittest
- Git y GitHub

## Instrucciones de ejecución

Instalar dependencias:

`pip install -r requirements.txt`

Ejecutar ejercicio 1:

`python ejercicio1.py`

Ejecutar ejercicio 2:

`python ejercicio2.py`

Ejecutar pruebas unitarias:

`python manage.py test sustentabilidad`

Iniciar servidor:

`python manage.py migrate`

`python manage.py runserver`

Acceder a http://127.0.0.1:8000/

Proyecto académico de EcoTech Solutions.
